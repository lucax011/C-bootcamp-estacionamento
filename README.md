# Estacionamento (C#)

Aplicação de console feita no bootcamp de C# e .NET da [DIO](https://www.dio.me), no desafio de fundamentos. Ela gerencia as placas dos veículos estacionados e calcula o valor cobrado na saída.

## Funcionalidades

- Definir o preço inicial e o preço por hora ao iniciar
- Cadastrar, remover e listar veículos pela placa
- Na remoção, informar as horas estacionadas e ver o valor: `preço inicial + preço por hora × horas`

## Como rodar

Pré-requisito: [.NET 8 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet run
```

```
1 - Cadastrar veículo
2 - Remover veículo
3 - Listar veículos
4 - Encerrar
```

## Conceitos praticados

Classes e construtores, `List<string>`, laços, `switch` e entrada e saída no console.
